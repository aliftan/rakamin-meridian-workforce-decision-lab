# Meridian Workforce Decision Lab

**Live demo:** https://aliftan.github.io/rakamin-meridian-workforce-decision-lab/

A self-contained interactive decision-support prototype for the Project Meridian workforce transition case study. Designed to help a Director of Human Capital explore automation exposure, modelled receiving-work capacity, evidence-backed redeployment pathways, and conditional Board decisions.

## Explore the experience

1. **Exposure map** — compare 12 illustrative job families by workforce scale, potential task exposure, absolute work equivalents, expected time-to-impact, and evidence confidence.
2. **Scenario lab** — compare assumed receiving capacity with required capacity; switch between zero/included contractor demand and gateable/non-gateable rollout. Select **Gap only** or **All components**, then hover or select a month to inspect displaced work, modelled matching, relevant attrition, and unresolved gap.
3. **Demand evidence** — distinguish claimed work from backed demand, feasible matching, and confirmed placement.
4. **Capability pathway** — inspect a fictional voluntary participant’s task evidence and the recommended human-reviewed next step.
5. **Board decision** — review decision gates and the least-confident strategic choice; print a concise snapshot.

## Key decision

**Demand-led redeployment** is the primary strategy. Selective rollout gating is a conditional operational lever that buys time only when verified receiving work and feasible transition preparation justify it; gating does not erase structural capacity gaps.

## How to run

Open `index.html` in any modern desktop browser. No installation, server, package manager, CDN, authentication, or network access is required. To publish, serve `index.html` as a static site (for example via GitHub Pages).

## Evidence and interpretation

The brief provides 52,000 enterprise employees, approximately 6,000 in the initial Field Metering cohort, and 70% technically automatable work in that cohort over an 18-month horizon. Other job-family allocations/exposure ranges, receiving-work demand, readiness, attrition, rollout curves, and economic quantities are **synthetic illustrations**, not Client findings. Work equivalents are **not** counts of individual employees selected for dismissal. Modelled matching is **not** confirmed placement. The current curves use model-anchored points with interpolation and an indicative, reconciled component decomposition; they are not a full live recalculation of the workbook.

The 36-month cash scenarios model contractor-related avoidable spending only. Other potential cash categories have not been modelled pending Finance evidence. Never interpret illustrative ROI as a verified forecast. Individual records are fictional; the product does not perform automated employment decisions.
