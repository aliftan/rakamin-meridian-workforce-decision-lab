# Meridian Workforce Decision Lab

An interactive demonstration of capability-based workforce decisions for the Project Meridian case. Open `index.html` directly or serve it as a static web page. It has no login, network dependency, CDN, or API connection.

**What this is:** A decision-support demonstration using brief facts and explicitly synthetic workforce and financial assumptions. The 36-month charts, economics, and sensitivity values are embedded snapshots extracted from the traceable internal workbook. The public page is not a live workbook view: changing internal assumptions requires a new export and regression check before redeployment.

**Suggested walkthrough:** Exposure → Solution AHA (Redesign work → Reveal capability → Test pathway) → Scenario Lab → Demand Evidence → Board Decision.

**Limits:** The fictional FM-027 profile is not an actual employee. No receiving roles are validated in the brief. Work equivalents are not headcount, and neither capability bands nor simulated matches authorize placement, contractual changes, or dismissals. Vendor economics assume avoidable contractor spend that has not been verified. Gateable cash ROI is deliberately unpriced.

**Review focus:** Confirm task evidence and human safeguards, scenario toggles, the distinction between cash and productive work value, and whether a Board could identify the exact evidence needed for the next decision.
